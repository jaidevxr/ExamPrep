## ✨ Key Features

| **🔥 Dashboard** | **🧠 Alpha Mode** |
|:---:|:---:|
| Complete overview of exams, subjects, and progress meters. Features a countdown timer and streak tracking to keep you motivated. | **Deep Focus Environment.** Minimal UI, integrated timer, ambient lofi music, and distraction-free navigation. |

| **📊 Analytics** | **📚 Content Tracking** |
|:---:|:---:|
| Visual metrics powered by **Recharts**. View subject-wise performance, study consistency, and motivation graphs. | Organize by **Subjects → Units → Topics**. Tick off completed topics and auto-sync progress to the cloud. |

#### 🎵 **In-App Media Player**
> Built-in Lofi music player with preset playlists and custom YouTube support to boost concentration.

#### ☁️ **Supabase Sync**
> Real-time data persistence across devices. Never lose your preparation stats.

## 📂 Project Map


src/
├── 🧩 components/      # Reusable UI components (Cards, Modals, Buttons)
├── 📄 pages/           # Main Application Routes (Dashboard, Auth, Analytics)
├── 🪝 hooks/           # Custom Logic (useAuth, useStudyTimer)
├── 🌐 contexts/        # Global State (AuthContext, MusicContext)
├── 💾 data/            # Static Data (Subject lists, Topics)
├── 🔌 integrations/    # Supabase Client Configuration
└── 🎨 assets/          # Static Assets (Images, Icons)

## ⚙️ Getting Started

Follow these steps to set up the project locally.

### 1️⃣ Prerequisites

Ensure you have **Node.js** installed.

### 2️⃣ Clone & Install


# Clone the repository
git clone [https://github.com/jaidevyadav/examprep.git](https://github.com/jaidevyadav/examprep.git)

# Navigate to directory
cd examprep

# Install dependencies
npm install


### 4️⃣ Launch App

npm run dev
